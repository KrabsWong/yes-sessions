# 使用指南

[文档首页](README.md) · 中文 · [English](../en/USER_GUIDE.md)

## 浏览会话

先选择数据源，再从按项目、日期组织的会话列表打开记录。有子会话的条目可展开，查看对应子 Agent 的历史。应用读取原工具保存的数据，因此不同工具的消息、用量和工具结果完整程度可能不同。

会话正文支持 Markdown、代码块、工具调用和结果、思考内容及附件。CodeBuddy CN 的用户提问与 IDE 附加上下文分开展示：展开「附加上下文」阅读环境、规则等内容，也可以复制原始消息。

右侧导航刻度用于快速跳转到提问；悬停可查看摘要。阅读较早消息时，新消息不会强制打断当前位置，点击新消息提示可跳到最新内容。Mermaid 图表可缩放、平移和重置；渲染失败时可查看原文并重试。

## 搜索

- `⌘F`：搜索当前会话。
- `⇧⌘F`：搜索当前选中工具的会话历史。
- 选择搜索结果后跳转到对应消息；`Escape` 关闭搜索。

跨会话搜索可能需要读取消息正文。历史较多时，搜索会比初次加载会话列表更耗时。

## 恢复会话

在支持的 CLI 会话中使用恢复入口，应用会打开首选终端并调用原工具。请提前安装对应 CLI，并在终端中完成它要求的登录或配置。OpenCode 2 会话使用 `opencode2`，其他 OpenCode 会话使用 `opencode`。

设置支持 Ghostty、Kitty 和系统终端。自动选择时依次尝试 Ghostty、Kitty、系统终端；指定的第三方终端不可用时也会回退到可用选项。项目目录仍存在时，会先进入该目录。

CodeBuddy CN 是 IDE 历史入口，不支持在终端恢复。继续工作请回到 CodeBuddy CN。

## 文件与 Git 变更

点击标题栏右侧的收起／展开图标打开面板，拖动边界调整宽度。

- **文件**：展开目录、搜索文件名、查看文本或图片。工具调用中的明确文件路径也可打开预览。
- **变更**：查看当前分支以及已暂存、未暂存和未跟踪文件。文本可切换合并视图或左右对比，图片可并排比较。
- **刷新**：检测到 Git 变化后，点击刷新读取新内容；预览不会自动替换你正在查看的内容。

预览顶部的返回按钮或 `Escape` 返回列表；在列表中按 `Escape` 收起面板。

这里显示当前磁盘文件与 Git 工作区，**不代表历史会话快照**，也不会通过预览修改文件。单文件读取上限为 4 MiB；文本最多 10 万行，每行最多 32 KiB。文件搜索最多返回 500 项，并限制遍历范围。超限或格式不支持时，界面会提示。

## 设置与窗口

用 `⌘,` 打开设置，可调整中文／英文、浅色／深色／跟随系统、阅读布局、思考内容显示和首选终端。文档默认中文不影响应用自身的语言设置。

| 快捷键 | 操作 |
| --- | --- |
| `⌘,` | 打开设置 |
| `⌘F` | 搜索当前会话 |
| `⇧⌘F` | 搜索当前工具的会话 |
| `⌘W` | 隐藏应用，保留当前阅读状态 |
| `⌘M` | 最小化窗口 |
| `⌘Q` | 退出应用 |

正常退出时保存窗口位置、大小和最大化／全屏状态。隐藏后从 Dock 打开，可继续当前阅读位置。
