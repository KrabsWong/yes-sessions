# 版本记录

## 11.8.1

- 新增静态 HTML 会话导出：主会话与可加载的子 Agent 页面会一起保存，支持页面内角色筛选，并遵循当前语言、阅读布局、思考内容显示和工具折叠设置。远端图片不会下载，未能加载的子会话会在报告中提示。
- 将 Rust CI 与 Release 的 macOS runner 更新为受支持的 `macos-15`，避免旧的 `macos-14` arm64 配置导致作业在启动前被取消。
- 将构建产物上传 Action 升级到 Node.js 24 对应的大版本，消除 Node.js 20 弃用警告。
- 补充中英文 README、使用指南和文档索引中的会话导出说明。

本项目沿用 GitHub Releases 自动生成发布说明；本页记录面向用户的主要变化。
