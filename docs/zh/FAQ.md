# 常见问题

[文档首页](README.md) · 中文 · [English](../en/FAQ.md)

## 为什么没有会话？

确认选择了正确的工具，并且该工具已在当前 macOS 用户下保存过会话。对照 [数据来源](DATA_AND_PRIVACY.md) 检查文件是否存在。CodeBuddy CLI 与 CodeBuddy CN 是不同入口；CodeBuddy CN 空会话不会展示。

若原工具修改了存储格式，可能需要适配。反馈时请说明工具版本、Yes Sessions 版本，以及脱敏后的数据结构。

## 为什么内容不完整或用量为零？

界面只能展示源记录中保存的信息。部分工具或会话不保存思考内容、Token 用量或附件正文；缺失统计不表示没有实际使用。已移动、删除或仅在远端存在的附件也可能无法预览。

## 为什么恢复失败？

先在终端确认对应 CLI 可以正常运行并已完成登录。检查项目目录是否还存在，以及设置中的终端是否可用。OpenCode 2 会话需要 `opencode2`。CodeBuddy CN 仅支持查看历史，请在原 IDE 中继续。

使用系统终端时，macOS 可能要求允许自动化控制 Terminal；若此前拒绝，可检查系统的隐私与安全设置。

## macOS 提示无法打开应用怎么办？

确认安装包来自项目的 [Releases](https://github.com/KrabsWong/yes-sessions/releases)，并查看该版本的签名说明。未公证包可在系统允许时，通过「系统设置 → 隐私与安全 → 仍要打开」放行。企业管理策略可能禁止此操作。

如果安装脚本在 `spctl` 检查时失败，说明安装包未通过系统评估。脚本不会自动绕过检查；请参阅 [安装脚本说明](INSTALL_SCRIPT.md)。

## 为什么文件预览与对话中的代码不同？

文件与 Git 面板读取当前工作区，并非历史快照。工作区后来发生的修改会体现在预览中。手动刷新可重新读取；大文件、过长文本或不支持的格式会提示限制。

## 关闭窗口后为什么还在运行？

`⌘W` 隐藏应用，保留会话与阅读状态。需要完全退出时使用 `⌘Q`。从 Dock 重新打开隐藏的应用即可继续阅读。

## 如何更新或卸载？

Homebrew 用户参阅 [安装、更新与卸载](HOMEBREW_CASK_GUIDE.md)。手动安装用户可退出应用后，下载新版本并替换「应用程序」中的旧版本；卸载时将应用移到废纸篓。原工具保存的会话不会因此被删除。

## 如何反馈问题？

在 [GitHub Issues](https://github.com/KrabsWong/yes-sessions/issues) 提供应用版本、macOS 版本、数据源及其版本、复现步骤、预期与实际结果。截图或样例先脱敏；无需公开完整会话历史。
